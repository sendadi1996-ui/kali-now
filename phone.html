دوس على الزرار وكتلقى كالي فالتليفون — بلا حساب، بلا فلوس
1. حمّل Termux (مرة وحدة) ولا: لينكس فالمتصفح ديركت

من بعد ما تحل Termux، لصق هاد الأوامر واحد بواحد:

pkg update -y pkg install proot-distro -y proot-distro install kali proot-distro login kali
من بعد ما تدخل لكالي، نصب الأدوات: apt update && apt install -y nmap whois dnsutils netcat-traditional curl whatweb
من بعد، Termux كيبقى فالتليفون — كل مرة غير حلو وكتب proot-distro login kali.
